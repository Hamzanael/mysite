04 ◇ AI Practice

AI as production infrastructure.

Architect & Builder · Spring AI · Multi-Tenant

I built the AI agent platform powering Analytick.

A production AI service running across Analytick's multi-tenant deployments — handling chat workflows, call transcription, and AI-driven QA evaluation. Multi-provider abstraction (OpenAI, Google Vertex Gemini, OpenRouter, DeepSeek, and self-hosted Ollama) via a factory/registry pattern, with per-tenant model configs encrypted at rest and decrypted on demand. Nine first-class agent tools — ticket query & creation, conversation history, document search, plus bilingual NSR entity/service/sector lookups for the Jordanian government use case. Full MCP (Model Context Protocol) support so agents can load external tool servers over STDIO or SSE.

pgvector-backed RAG with org_id + agent_id filters enforcing multi-tenant isolation; Vertex AI embeddings, top-K retrieval at a 0.7 similarity threshold, and bidirectional PDF text handling for Arabic documents. Every LLM call and tool invocation is recorded to a MongoDB session-flow collection for audit. Built on Spring AI · Kotlin · virtual threads · OpenTelemetry. Outside Analytick, I'm also Careem's #1 organization-wide AI power user — automated 80%+ of new test coverage and accelerated legacy migrations.
